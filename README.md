# Da Estatística ao Python

Caderno de campo interativo do minicurso **Visualização de Dados em Python para Pesquisa em Ciências Sociais**, feito para a Semana Acadêmica de Ciências Sociais da UFV.

O material serve de ponte entre a disciplina de Estatística e a análise de dados com Python. Ele pode ser usado durante o minicurso e também depois, para estudo autônomo.

## O que tem

- **14 dias** que seguem a história de uma pesquisadora na Vila Boa Esperança, do primeiro `print()` ao relatório final.
- Estatística descritiva com código: frequências, média, mediana, moda, desvio padrão, quartis, boxplot, histograma, comparação entre grupos e correlação.
- Código comentado, com explicação linha a linha, e gráficos gerados com pandas, matplotlib e seaborn.
- Testes de campo que liberam carimbos e, ao final, um certificado.
- Páginas sobre ética em pesquisa e uso responsável de IA, com base nas diretrizes da UFV.
- Uma ferramenta de perguntas para a discussão final do minicurso.

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada, e o progresso e o nome ficam salvos no próprio navegador.

Para rodar os códigos de verdade, use o [Google Colab](https://colab.research.google.com/). O Dia 1 explica o passo a passo.

## Dados

A base de dados usada é **fictícia**, criada só para ensino. Não tire conclusões sobre a realidade a partir dela.

## Como publicar

No GitHub, vá em **Settings → Pages**, escolha a branch principal e a pasta raiz. O endereço aparece ali em alguns minutos.
